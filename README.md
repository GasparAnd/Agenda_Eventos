# 🪁 Agenda de Eventos — Sapupara/Tabatinga

Bem-vindo ao projeto **Agenda de Eventos**, uma página web desenvolvida com HTML e CSS para apresentar eventos culturais, esportivos e comunitários da região de Sapupara/Tabatinga, em Maranguape — CE.

O projeto tem como objetivo divulgar eventos da comunidade por meio de uma página simples, organizada e com um visual inspirado no céu azul e nas pipas.

## 🌤️ Sobre o Projeto

A página apresenta três eventos, com informações sobre suas datas, locais e descrições.

O design utiliza tons de azul para representar o céu, combinados com cartões claros para facilitar a leitura e destacar as informações.

## 🎉 Eventos

### 🪁 1. Festival de Pipas

Um encontro de pipeiros para participar de desafios que envolvem habilidade, criatividade e diversão.

**Atrações:**
- Disputa de altura;
- Concurso de beleza das pipas;
- Disputa mata-mata.

📅 **Data:** 29 de novembro de 2026  
📍 **Local:** Campo do Mirante, distrito de Sapupara, Maranguape — CE.

### 🎭 2. Feira Cultural

Uma tarde de música, dança, teatro e apresentações artísticas, celebrando a criatividade e a diversidade cultural.

📅 **Data:** 12 de dezembro de 2026  
📍 **Local:** Escola local da comunidade João Cirino Nogueira.

### ⚽ 3. Campeonato Esportivo

Um evento dedicado ao esporte, à integração dos participantes e ao incentivo ao trabalho em equipe.

📅 **Data:** 19 de dezembro de 2026  
📍 **Local:** Areninha esportiva da comunidade.

## 🎨 Identidade Visual

O projeto utiliza uma paleta de cores inspirada no céu e nas pipas:

- 🔵 Azul-céu: fundo principal da página;
- 💙 Azul-escuro: títulos e elementos de destaque;
- ☁️ Branco: cartões e áreas de conteúdo;
- 🩵 Azul-claro: detalhes e seções;
- 🔴 Vermelho: destaque das datas.

## 💻 Tecnologias Utilizadas

- **HTML5:** estruturação do conteúdo;
- **CSS3:** estilização, cores, espaçamentos e organização visual.

Todo o CSS é interno, utilizando a tag `<style>` no documento HTML, conforme solicitado na atividade escolar.

## 📚 Recursos de HTML e CSS

O projeto utiliza:

- Seletores por elemento;
- Seletores por ID;
- Seletores por classe;
- Cores em hexadecimal, nomes e RGB;
- Formatação de títulos e parágrafos;
- Destaque de datas;
- Efeito `hover` nos links;
- Sombras e bordas arredondadas;
- Classe especial para destacar um evento.
